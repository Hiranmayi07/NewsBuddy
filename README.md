# 📰 NewsBuddy – AI-Powered News Assistant

NewsBuddy is a web-based application that provides daily news updates along with an AI-powered assistant to help users understand, summarize, and interact with news content intelligently.

---

## 🚀 Features
- 🗞️ Daily news generation from multiple sources  
- 🤖 AI assistant to answer questions and summarize news  
- 🔍 Category-wise and topic-based news browsing  
- 🌐 Clean and user-friendly web interface  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python (Flask)  
- **AI / NLP:** Hugging Face / LLM APIs  
- **Database:** SQLite  
- **Version Control:** Git & GitHub
